This project's modified model assets (`skin.glb`, `skeleton.glb`, `muscles.glb`) are distributed under CC BY-SA 4.0, subject to retained upstream attribution and applicable component conditions.

Modifications: selected surface-region, skeletal and muscular mesh collections; omitted hairs, collection title meshes, point/line annotations, internal organs and nervous-system collections; evaluated geometry, repaired invalid mesh data, assigned neutral layer materials, and exported separate glTF/GLB layers. Original anatomical coordinate system is retained through standard Blender-to-glTF axis conversion. Source and output SHA-256 hashes and included structure names appear in `manifest.json`.

The complete Z-Anatomy source lists additional third-party components with separate licenses, including some NC material. The exporter does not select the brain, white matter, inner ear or kidney collections; the full atlas must not be assumed to have a single uniform license. No Wikipedia definitions or source Blender scripts are used in the website.

These models do not include certified acupoint positions. New acupoint marks and bone-cun endpoints are local unreviewed drafts, not medical approval. Source anatomical names are retained for traceability, not independently certified by this project.
