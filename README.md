# 痧证汇方

**痧证汇方中医刮痧知识管理与可视化系统 V1.0**

独立网站仓库，不包含长征主题网页。

## 功能

- 病证检索、书籍筛选与辨证方案阅读
- 三维穴位图谱、经脉筛选、骨度尺与热点定位
- 刮痧知识词典
- 多方案并列对比与文件导出

## 运行与发布

静态站点位于 `dist/`。可运行 `python -m http.server 8799 --directory dist` 后访问本地地址。
GitHub Pages 从 `main` 分支的 `docs/` 目录发布；`docs/` 中网页与 `dist/` 同步。

## 第三方素材与使用范围

模型许可和署名见 `dist/models/z-anatomy/ATTRIBUTION.md`，Three.js 保留源文件许可。公开仓库不代表授予所有教材、数据、图片或其他第三方内容的再使用权；相应权利归原权利人。本项目原创代码未在此额外授予开源许可。

本系统仅供中医养生知识学习参考，不能替代医师诊断与治疗。图谱显示和几何计算不构成临床定位精度或医学认证。
